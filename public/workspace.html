Koneksi LLM & pencarian RAG

Kunci API disimpan di server. Status konfigurasi belum menjamin kuota atau akses model.

Memeriksa…

Provider mengikuti RAG_PROVIDER di .env: ollama (lokal, gratis) atau openai (perlu kunci). Konfigurasi dibaca ulang tanpa memulai ulang server. Model tidak dilatih atau diunduh otomatis.

Batas versi awal

Impor TXT, Markdown, dan CSV standar. Pengambilan publik dibatasi ke daftar terkurasi. PDF/XLSX, perhitungan lintas baris, serta integrasi portal resmi belum diaktifkan. Riwayat percakapan tersimpan di browser ini; sumber tersimpan di SQLite lokal.
